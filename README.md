# Shop Bot

Telegram-бот интернет-магазина с корзиной, написан на aiogram 3.

## Стек
- Python 3.13
- aiogram 3.30
- aiosqlite
- python-dotenv
- Деплой: Railway

## Функции
- Каталог товаров с инлайн-кнопками
- Добавление товаров в корзину (с накоплением количества)
- Просмотр корзины с автоматическим подсчётом суммы
- Оформление заказа с очисткой корзины

## Команды
- /start — приветствие
- /help — список команд
- /shop — посмотреть товары
- /cart — моя корзина

## Запуск локально
1. Клонировать репозиторий
2. `pip install -r requirements.txt`
3. Создать `.env` с `BOT_TOKEN=твой_токен`
4. `python main.py`
